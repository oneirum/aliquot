# Study methods guide

Synthetic document for the lab0 router check. Not a real lab's statistics advice.

## Sample size
For a two-group comparison at a medium effect (d = 0.5), plan 64 participants per group for 80% power at alpha 0.05.

## Power analysis
Run the power analysis before enrolment and report the effect size, alpha and power you planned for in the preregistration.

## Mixed models
Repeated nights from the same participant are not independent. Fit a mixed model with a random intercept per participant.

## Missing data
Report how much is missing per variable. Use multiple imputation when data are missing at random; never drop whole participants by default.

## Multiple comparisons
When you test several outcomes, control the false discovery rate with Benjamini-Hochberg and say so in the methods.

## Preregistration
Preregister the hypotheses, primary outcome and analysis plan on OSF before you look at the outcome data.
